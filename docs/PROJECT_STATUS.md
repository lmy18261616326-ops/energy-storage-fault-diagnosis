# 项目状态与指标口径

## 1. 结论

本项目已经完成“仿真—数据—建模—冻结—盲测—诊断”闭环，适合作为储能控制、电力电子、故障诊断或工业机器学习方向的简历项目。

当前状态是：

- **研究流程已完成**；
- **仿真范围内的可观测性增强已形成证据**；
- **模型部署晋级仍被阻止**；
- **硬件/HIL 尚未执行**。

## 2. 官方评估轨道

### 2.1 v13 冻结盲测：用于证明早期模型的泛化缺口

- 开发集：696 个 RunID，138,504 个窗口，57,856 个合格窗口，28 个工况。
- 盲测：模型冻结后新生成 216 个 Run，仿真失败 0。
- 一次性盲测 Macro-F1：43.79%。
- S1/S2 开路召回率：均为 13.79%。
- 健康误报主要集中在两个 600 W、ModeCommand=1 新工况。

该结果的价值是证明“开发期指标不等于新工况泛化”，并驱动 v06 器件可观测性设计。

### 2.2 v17 仿真主任务：用于证明当前主动可观测范围内的可分性

- 416 个独立 Run，28 个工况，按工况分组 OOF。
- Extra Trees、逻辑回归和随机森林在该范围的 Run 级 Macro-F1/Accuracy 均为 1.0。
- 100% 只是指定仿真范围内的点估计，不是真实部署保证。
- 高阻器件直接观测结果仍受理想 Ron、仿真器件和样本数限制。

### 2.3 v19 合成参考 HDF5：用于方法与负对照审计

- 固定 Extra Trees 基线 Macro-F1：0.9493。
- 六折外层+五折内层嵌套选择 Macro-F1：0.9072。
- 健康误报率：0。
- 高阻召回率：0.9048。
- 故障前负对照 Macro-F1：0.1511，接近六类随机水平 0.1667。
- 由于合成数据存在标签相关 seed 范围风险，`promotion_blocked=true`。

因此，简历可以写“建立负对照和晋级门禁”，不能写“模型已在实测环境达到 94.93%”。

### 2.4 外部实验数据：用于域偏移和状态可分性

- 9,261 行，441 个网格位置分组，21 个 C 状态。
- 状态可分性 GroupKFold Macro-F1：0.5044；随机水平约 0.0476。
- 与冻结模型共享特征覆盖：100/950，即 10.53%。
- 外部特征单元中 82.61% 超出合成训练最小-最大范围。
- 外部标签与冻结六类故障无重叠，所以不计算外部故障准确率。

## 3. 当前模型晋级门禁

以下条件没有同时满足之前，模型状态保持为“研究原型”：

1. 新生成的冻结盲测中，噪声/相位种子与标签独立；
2. 数据集生成脚本、配置、随机种子和文件哈希冻结；
3. 评估仅执行一次，不在盲测上调参；
4. 报告 Run 级指标、置信区间、健康 FAR 和逐类召回率；
5. 明确仿真、合成、外部波形和硬件证据边界。

## 4. 简历可用口径

- “完成 912 个开发/盲测仿真 Run”是可用的（696 开发 + 216 盲测）。
- “通过冻结盲测定位开关故障漏检”是可用的。
- “嵌套 OOF Macro-F1 90.72%”必须加上“合成参考域”。
- “外部实验数据验证了故障准确率”不可用。
- “已部署”、“已量产”、“已达到功能安全要求”不可用。
